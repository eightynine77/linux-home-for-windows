# linux home for windows
this is a windhawk mod that provides the linux home directory shortcut path `~/` for windows

# how to use
### step 1: open windhawk 
install it first if you haven't installed it
### step 2: click "create a new mod" button on the bottom-right corner (the one with a pencil icon)
### step 3: paste the content of the [linux_home_mod.cpp](https://github.com/eightynine77/linux-home-for-windows/blob/main/linux_home_mod.cpp) file into the editor
### step 4: save it by pressing [ctrl] + [S] on your keyboard
### final step, step 5: compile it by pressing the "compile mod" button on the left sidebar
and now you're done. to exit the editor, click "exit editing mode" button on the left sidebar
